## Checked and found safe
- **Category 1:** I read all source and found no `eval`, `exec`, `pickle`, `yaml`, `marshal`, `subprocess`, `os.system` or SQL. Storage is plain dicts. The only regexes are in the hook and run on agent commands, not app input.
- **Priority validation:** `services/tasks.py:_validate_priority` rejects bool and non-int values and enforces 1–5. `done` requires `isinstance(done, bool)` (line 252 in the file).
- **Field allowlist:** `repositories/tasks.py:64-65` filters by `_UPDATABLE_FIELDS`, so `id` and `user_id` can't change through `update()`. Rows are replaced, not mutated.
- **Notifications:** `services/notifications.py:41,65` return fresh dicts rather than live rows. Bool ids and non-str or out-of-list prefs are rejected (`:18`, `:63`).
- **Layering:** `routes/` import only `services/`, and `services/` import only `repositories/` and `utils/`. There is no cross-service import.
- **Secrets in history:** `git log --all -p -- '.env*'` is empty. A scan of all history for `sk-`, `AKIA`, `ghp_`, private-key headers and credentialed DB URLs found only the fake `u:p@localhost` fixture in `tests/test_guard_writes.py:123`. No `.env*` file exists, and the only file ever deleted is `CLAUDE_pre_PA5.md`.
- **Prompt injection:** A grep of tracked files for "ignore previous", "disregard", "you must now" and "system prompt" found only the scan command's own text. The untracked `docs/security-scan-output.md` is empty. This was a keyword grep, not a full read of every markdown log.
- **Hook coverage that works:** Case-insensitive path matching, `..` normalisation, redirects, `cp`/`mv`/`tee`/`sed -i`, `rm -rf` (token-level) and `git push --force` or `-f` are handled in `guard_writes.py`.
